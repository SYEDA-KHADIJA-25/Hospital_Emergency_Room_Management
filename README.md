# Hospital_Emergency_Room_Management
Team Composition and Role Distribution
The success of the Hospital Emergency Management System (HEMS) is attributed to a structured division of labor, ensuring each technical module was handled by dedicated specialists.
1. Project Management & Integration: Team Leader (Syeda Khadija Naqvi):
GitHub Governance: Managed the version control system, resolving merge conflicts between the backend and frontend teams.
System Integration: Acted as the architect to ensure that Module 1 through 4 communicated seamlessly without memory leaks.
Quality Assurance: Conducted stress tests on the Priority Queue and BST to ensure stability under heavy data loads.

2. Technical Documentation & LaTeX: LaTeX Report Specialist (Ahmed Suhaib & Sultan Naeem):
Technical Writing: Translated complex C++ logic into professional prose.
Visual Documentation: Curated diagrams, flowcharts, and high-resolution screenshots of the Dear ImGui interface.
Academic Standards: Ensured the report met all formatting, citation, and structural requirements for a final year project.

3. Core Development Modules:
The backend and frontend development was divided into four specialized functional units
Module 1: Patient Triage (Tariq Ahmed & Umer Ali Khan):
Implemented the Min-Heap for automated patient prioritization.

Module 2: Doctor & Resource Allocation (Dawood Amin & Muhammad Kamal):
Utilized Queues for doctor availability management and Linked Lists for dynamic resource (beds, rooms) tracking.
Ensured that resources are updated in real-time as patients are admitted or discharged.

Module 3: Medical History & Records (Mehboob Akbar & Adil shah):
Implemented persistent storage using File I/O to save and load patient history.
Used tree-based structures to categorize medical records by date and severity.

Module 4: GUI & Dashboard (Syeda Khadija Naqvi):
Integrated the Dear ImGui library with the backend C++ logic.
Developed the visual dashboard, including real-time charts and color-coded priority lists for the emergency room staff.
